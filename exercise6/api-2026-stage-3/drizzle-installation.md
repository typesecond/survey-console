## Installation notes for Drizzle ORM + Postgres

Drizzle was set up for Postgres as described [here](https://orm.drizzle.team/docs/get-started-postgresql#step-1---install-packages).

## Drizzle-kit

See [here](https://orm.drizzle.team/docs/kit-overview) for an overview of drizzle-kit.

Example commands:

Create the development database:

```
drizzle-kit push
```

Create the test database

```
NODE_ENV=test npx drizzle-kit push
```
